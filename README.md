# 🚆 Public Transport Delays Prediction

> Predecir retrasos del transporte público a partir del clima y eventos de la ciudad.

**Estado:** 🚧 En construcción — ver [`ROADMAP.md`](ROADMAP.md) para el plan completo por fases.

## 🎯 Objetivo
Regresión sobre la duración del retraso (minutos) combinando condiciones climáticas, eventos
urbanos y patrones temporales, con análisis de la contribución de cada factor.

## 🛠️ Stack previsto
Python · pandas · scikit-learn · XGBoost · matplotlib / seaborn

## 📄 Dataset
[Public Transport Delays with Weather and Events — Kaggle](https://www.kaggle.com/datasets/khushikyad001/public-transport-delays-with-weather-and-events)
(no incluido en el repo — ver instrucciones en el ROADMAP).

> ⚠️ Nota: el dataset es pequeño (~2,000 filas) → priorizar modelos simples + validación cruzada.
